# Proxima Phase 3：自定义同步串行接口（CSPI）连接与总线巡检
# 连接 H5-2(CSN)、H5-3(DO)、H5-4(DI)、H5-5(CLK)、H5-6(GND)、
# H8-1(EN_RM) 到 CH347 board；EN_RM 的连接/电平由硬件设置。
# w2/r2 = 16bit CSPI数据位宽；w4/r4 = 32bit CSPI数据位宽。

# 1. 读取 CR5 的初始值（应在上电/复位后、写入测试值之前检查）
r4 0x1014 # CR5：期望 0x00005555

# 2. 如果上述值不正确，先排查再继续：
# 用逻辑分析仪连接 H5-2(CSN)、H5-3(DO)、H5-4(DI)、H5-5(CLK)、
# H5-6(GND)、H8-1(EN_RM)，抓取上述 CR5 CSPI 读信号进行分析。
# 此步骤为人工操作；当前命令文件不能按读值条件分支。

# 3. 写入 CR5 测试值

# 4. 读回 CR5 并校验
